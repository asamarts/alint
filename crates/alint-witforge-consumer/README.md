# alint-witforge-consumer

Compile and round-trip proof for the committed `alint:plugin@0.1.0` WIT contract.

The `src/plain`, `src/proto`, and `src/glue` modules are generated by the witforge
0.1 candidate, with the protobuf module produced by `prost-build` and the
proto3-JSON impls by `pbjson-build`. The test constructs every contract shape,
exercises the adapter and analyzer helpers, and round-trips requests and
responses through protobuf binary and proto3-JSON.

Do not hand-edit the generated modules. Regenerate them with the candidate
binary and the instructions in [`wig/README.md`](../../wit/README.md); the
pre-publication check is:

```sh
WITFORGE_BIN=/path/to/witforge ci/scripts/witforge-consumer.sh
```

The crate name is deliberately a consumer proof, not the production
`alint-plugin-api` crate. It is removed or replaced when alint adopts the
published generated crate.
