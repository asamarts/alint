# alint plugin contract (WIT draft)

`alint-plugin/0.1.0/plugin.wit` is the draft `alint:plugin@0.1.0` contract:
shared std-only types, an `adapter` world, and an `analyzer` world. Inputs are
host-pushed; there are no host callbacks, resources, handles, or recursive
types in this version. `wire.lock` is the append-only protobuf wire-number map
generated by witforge.

The WIT is a design artifact until witforge's Rust/protobuf emitters land. The
hand-written traits in `alint_core::plugin_api` are the executable contract for
v0.21.

Validate the subset and lock continuity with witforge:

```sh
witforge check wit/alint-plugin/0.1.0
```
