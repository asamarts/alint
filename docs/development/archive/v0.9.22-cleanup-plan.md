# alint v0.9.22 cleanup plan

> **Status**: locked-in plan; Batch A in progress as of 2026-05-14.
> **Source audit**: comprehensive audit on 2026-05-14 of alint + alint.org repos.
> **Decisions captured**: 2026-05-14.

A doc + prevention-automation cycle following the v0.9.21 release. The audit surfaced 10 categories of drift between the alint repo and the alint.org repo. This document is the agreed plan to fix them and prevent recurrence.

## Decisions locked in (2026-05-14)

- **Rule-count canonical**: **70 across 13 families** (matches `all_kinds.yaml` audit gate)
- **LSP design docs**: **move from `v0.10/` to `v0.11/`**; rewrite `v0.10/README.md` as case-study coverage scope
- **Public roadmap sync**: **generate from canonical at build time** via section markers (Batch E)
- **Workspace internal-dep versions**: **bump to `workspace.package.version` + preflight check** (lockstep)
- **npm shim version**: **bump to 0.9.21 + lockstep with workspace** every release
- **`docs/development/`**: **keep all + add README** with per-file audience labels
- **PROPOSAL-AGENTS.md**: **refresh as current-state vision doc** (separate session)

## Risks + mitigations

- **C2 (rule-count test) may be brittle on README phrasing changes.** Write the regex permissively; test against the actual README in the same PR.
- **B2 version bumps could surface latent semver issues for downstream consumers.** Lands before next `cargo publish`; verify with `cargo publish --dry-run` per crate.
- **C3 cross-repo check needs GitHub Releases API access.** Use unauthenticated public-API endpoint; fall back gracefully on rate limit.
- **B1 `git mv` preserves history but breaks any external link to `v0.10/lsp_server.md`.** Search alint.org content for `v0.10/lsp_server` and add a redirect stub if any references found.

## Out of scope for v0.9.22

- Rust code-quality review (clippy, perf) beyond preflight
- CHANGELOG entry composition for v0.9.22 — written when batches A–D land
- Schema / report-format changes — v0.9.22 is doc + prevention only
- Case-study revalidation runs against the corpus
- Cross-repo migration of `marketing/` artifacts — keep alint.org-only convention
